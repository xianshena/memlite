## 复现从哪里开始

先用已经公开的低成本入口理解输入—状态—选择，再读保存结果：

```sh
python -m examples.cpu_quickstart
python -m unittest discover -s tests -p test_object_memory.py -v
python -m scripts.audit_recorded_results
```

这些是现有CPU示例和离线审计，不会从头训练308M。本轮显微镜模型源码、冻结测试及权重尚未在仓库公开，
因此不能承诺从本目录一键复跑它。具体本地入口及核验层级见[来源导航](experiments/microscope-20261027/sources.md)。

LifeDynamics保留为来源另有署名的参考材料，不列为用户独立完成的实验，也不随本轮发布其代码或数据。
