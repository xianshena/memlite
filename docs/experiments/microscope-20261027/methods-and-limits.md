# 方法、分母与统计边界

[总报告](README.zh-CN.md) · [统计JSON](summary.json)

## 网络与训练

A是小型中文分类：文本字符经过嵌入，由CNN、GRU或Transformer编码，再输出动作／物品／地点三个头；
每头5类，包含本任务的无关槽约定。它不是旧小狗的10／7／6类接口。词袋对照没有字符顺序。
交叉熵训练正确类概率，三个头的损失相加，不能把损失值直接当准确率。

B1输入结构化事件，输出33类（32个值与NONE）。门控参考以有限矩阵状态逐步读写；
coupled与separate可训练参数均1,065,825，投影、层、状态形状和读出相同，改变擦除／写入门的规则。
这不是论文全规模实现、优化内核速度复现或通用语言模型。B2把完整五元素排列编码为120类。

v1.1原定各配置1,024次AdamW更新、学习率3e−4，验证NLL在512／1,024步快照中选模。
A的批量为32；其余配置以冻结计划为准，不能把一个配置的batch套给全部模型。
四个事后B1续训虽保持原定步数，仍有测试时序上的方法偏离。

## 三类成对／成组指标

1. A完整三槽准确率的分母是1,200行；全部成对正确率分母600对。
   主要GRU—Transformer比较只看300对同指令／新情境；另300对为同情境／新指令。
2. B1逐条分母864，双生对分母432。决定性历史不同、末64事件相同；两个答案都对才算一对成功。
3. B2逐条分母1,536，384个基础episode各有base、reversed、single_edit、same_multiset_reordered四变体。
   全组正确要求四侧都对。原主要配对比较使用每episode四侧正确率的平均值，不是“全四侧都对”率；两种指标必须分别报告。

主要比较按种子11／23／47分别做2,000次配对cluster bootstrap，保留95%百分位区间，
有意义差异阈值5个百分点。没有把三个种子视为三倍独立测试。区间包含零或不能排除小于5个百分点差异时，记为不确定，
不把“未检出差异”写成“两个机制相等”。

## 重复输入与测试分布

本次另行按原始A输入文本去重，得到训练705种、验证468种、测试165种。
验证与训练共享460种输入；测试与训练／验证交集均0。无相同测试文本并不意味着完全不同语义分布。
原数据审计检查ID、规则、组合和配对，但没有据此保证每行文本独立。

原bootstrap使用pair_id，尚未按重复文本族或共享模板重新建模。既有区间是该方法的条件结果，
不能被包装成165种文本之外的通用中文分布结论。本轮复算原统计，没有追加修正实验或新模型测试。

B1的测试NONE基线为144/864。九组模型几乎都输出NONE，双生对全错，
所以16.67%不是长期记忆成功。B2最多标签基线为23/1536，忽略顺序基线24/1536；
模型约0.8%的分数没有超过这些对照。独立数据审计还记录B2测试操作次数全为偶数，训练／验证有奇偶混合；
未见操作组合的结论不能完全排除这种同时发生的分布变化。

## 验证的层次

- 本次只读核验60份小结果／压缩预测文件的SHA256，与合并lineage逐一一致。
- CPU离线复算30组、36,000条预测的评分、分层、成组结果及原配对区间，与保存汇总一致。
- 相同任务的cluster ID在架构和种子间复用，36,000不是独立场景数。A文本还有额外重复。
- 原包回执报告331＋68文件归档通过；本次未重新读取或散列大权重，也未复跑GPU。
- 本次没有新GPU测试，因此不存在“本轮GPU测试已通过”的说法；既有仓库CI只检查其现有CPU项目。

输入审计通过、预测重算一致、重新加载权重输出一致、真正独立外部复现，是不同层次。
当前材料不证明真实机器人控制、自然视觉、持续人格、AGI，或某架构普遍胜出。
