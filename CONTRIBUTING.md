# Contributing

This is an early project. Useful contributions include reproducible bug reports,
CPU portability checks, clearer diagnostics and independent replication attempts.
Describe your environment, exact command, expected/observed behavior and relevant
non-sensitive logs. Keep recorded evidence unchanged; write new outputs to `runs/`.
Label new experiments separately and report failures. Do not upload personal
transcripts, credentials, company data or unlicensed third-party material.

Run the CPU checks and record audits in the README before proposing a change.
GPU claims need their actual environment, seeds, protocol and measured results.
No maintainer response-time or external-adoption promise is made.
